# Support Queue

An IT helpdesk ticket management application that ensures the most pressing
ticket is always shown first.

## Features

- Create support tickets
- Urgent and normal priorities
- Automatic response deadlines
- Overdue ticket detection
- Smart ticket prioritization
- Search tickets by customer
- Filter overdue tickets
- Filter tickets assigned to Priya
- Filter urgent tickets
- Update ticket status
- Pagination
- Local storage persistence

## Tech Stack

- React
- JavaScript
- CSS
- Vite
- Browser LocalStorage
